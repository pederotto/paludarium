# Z0 proposal (step 1, analysis only; 10 tool calls total)
1. Approach = amph-life-day.mjs in a fresh Chrome on the dev server (plain node cannot load the world, MAP.md:15). In-page: `game.frozen=true`, `await game.loadTank(tier,{layout:'empty'})` (amph-life-day.mjs:48), then ONE synchronous block: seed `Math.random` (mulberry32, :53-56) + virtual `performance.now` (:57-58), `generateTerrarium(w,{preset,seed,tier})` (:49; it adds the preset's own animals with the generator's rng, generator.js:321-334), `A.syncOccupancy(true)` (:51), then `--mix` via `A.placement(id,{point,surface})` + `A.add` (:67-73, animals.js:791/842). Stubbing rAF after loadTank keeps the page's render loop from consuming the seeded stream; ids come from module counter `nextId` (animals.js:845) so rows carry id = `species-k` (k = creation order) plus `uid`.
2. Stepping as the game does (game.js:206-208): `W.sim.step(dMin); W.animals.move(dtA)`. "Sim second" = animal second, `A.t` (animals.js:909); game minutes per animal second `warp` = speed/min(speed,4) (SPEEDS tank.js:49, MINUTES_PER_SECOND :48, game.js:208 uses min(speed,4)). Flags: `--dt=0.1` animal s per move() (stuck.mjs uses 0.2), `--speed=1` (1x = 1 game min per animal s, so 2 sim hours = 5 game days; start 06:00 as amph-life-day), `--every=10`, `--care=1` (prey topped up + health>=0.8 each game hour, as amph-life-day.mjs:203-206; `--care=0` leaves it bare). Chunks of N frames per `page.evaluate` (synchronous inside; Math.random swapped in only during a chunk), rows streamed to the .jsonl so a crash keeps the partial dump.
3. Fields (animals.js unless noted): pos `a.pos` x,y,z cm (:848; wall geckos: z follows the wall relief, :1105-1107); speed `a.speedNow` cm/s (:957, frogs divided by tf); mode `a.hm.mode` (herp mind, :3854, herp.js:112: rest/hide/forage/hunt/soak/air/flee/warn/retreat/court...) or `a.sk.mode` (skink, :2329, skink.js:51) else `a.state` (:850); doing `a.doing` (:3929, shrimp :1734); onWall `a.onWall` (gecko, :3858), wallMode `a.wallMode` (:931, 1048), perch `a.perch.ph` (:2107), swimming `a.swimming` (:2662), hop `a.hop`, dead `a.dead`, asleep `a.hit?.tuck` (:3919); goal `a.hm.goal` / `a.sk.goal` (:3905, skink.js:51) else `a.target` (:1759); a wall goal lives in the mind's plane (x, z=-y) (:3864), so goal distance is measured in that plane for onWall animals; inWater = `waterTop(x,z)>-Inf && pos.y<waterTop` (:1040); inSolid = raw `A.occ.solidAt` at body height `pos.y+min(0.5,h/2)` and `pos.y+0.8h` (both, as insideSolid :1048-1052; false when onWall/hop/wallMode; swimmers: at pos.y); the game's own verdict is in the footer (`A.stuckStats` :606, `.inside`, `.by`). Body length for pile = `SPECIES[id].anim.rig2.len` (skink 16.8, :407) else 4*size, written to the header (gecko value NV).
4. Row (JSON line, 2 decimals): `{"t":120.1,"h":6.04,"id":"gecko-0","uid":57,"sp":"gecko","x":-12.34,"y":5.6,"z":3.2,"speed":1.2,"mode":"forage","doing":"Hunting a springtail","awake":1,"onWall":0,"wallMode":0,"perch":null,"swim":0,"inWater":0,"inSolid":0,"gx":-9.1,"gz":4.4,"gd":4.1,"tun":0}` ; `awake`=0 when mode is hide/rest or tucked; `gx,gz,gd` null without a goal; `tun` = tunnelling steps since the previous sample. First line `{"hdr":1,preset,tier,seed,every,dt,speed,mix,sizes}`, last `{"end":1,frames,wallS,errors,stuckStats}`. Written to CONTRACTS.md "State dump row".
5. Counters (pure, `state-counters.mjs`; also `node tools/steps/state-counters.mjs dump.jsonl --T=12`): `stuck(rows,{T=12,r=1})` awake + goal + within 1 cm of the run's anchor longer than T s (needs `--every` <= T/3); `pile(rows,{T=300})` connected groups of >=3 within one body length whose >=3 common members persist > T, reported for awake animals (default) and for all (geckos legitimately sleep in groups, herp.js:523); `waterTime(rows)` share of rows inWater per species, all and awake; `inSolid(rows)` rows/animals/episodes per species; `tunnel(rows)` = sum of `tun`. Tunnel CANNOT be derived from the dump (no solids in it, samples 10 s apart): it is counted in the page per move(), segment prev->cur sampled every 0.5 cm, counted when both ends are free and a sample is solid; moves > 3 cm (relocations, amph-life-day.mjs:131 `mv<3`) and hops/wall are skipped.
6. Determinism: same seed twice => byte-identical .jsonl is the requirement, no numeric tolerance (the sim is chaotic: any divergence grows). Risks: Math.random consumers outside my synchronous blocks, `nextId` (handled by `id`), `jobs.js:21-25` time budget (virtual clock). Verified only by the check; if it fails the dump says where (first differing row).
