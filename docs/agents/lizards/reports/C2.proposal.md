# C2 proposal: follow mode (analysis only)
Machine (new src/editor/followmode.js, pure, no imports): `step(state, ev) -> { state, fx[] }`. States: `free` (menu on, camera the player's), `focus` { target, home } (following an animal or zoomed on any selection). Events: follow(a), zoom(sel), esc, tap(hit), dbl(hit), long(hit), lost (followed animal died/removed: controller.js:484-489).
- free -> follow/zoom: fx saveHome (only here, never while in focus), hideMenu, select(target), follow(a) if an animal. free + tap/dbl/long: today's behaviour (no fx).
- focus -> esc | tap(anything) | lost: fx restoreHome (animated), showMenu, follow(null); esc also select(null); a tap on a thing selects it (C1 panel opens for it, camera still goes home).
- focus -> dbl(animal B) | long(animal B), B != target: fx follow(B), select(B); home kept, menu stays hidden. dbl/long on the same animal or on nothing: no fx.
Home pose: the controller stores `home = { pos, target }` from camera-controls (getPosition/getTarget) at the saveHome fx; restoreHome = controls.setLookAt(pos, target, true). Kids reset() KidCard.jsx:68-70 is the pattern to copy, not shared.
Tap vs double-click without delaying every tap: in free, taps act at once (no change). In focus, a tap whose pick finds no animal other than the target exits at once (a dbl there means nothing); only a tap on another animal waits 300 ms for a second tap (pointerup e.timeStamp, 6 px, the existing _taps). Long-tap: a 500 ms timer from pointerdown (cancel on 6 px move, up, cancel), it picks at the down point and marks the press so pointerup does not tap.
Menu: one signal `S.focusHide` (store.js) mirrored as body class `focus-hide` (like zen, fullscreen.js:65); hud2.css hides .topbar, rail, tool options, status drawer, bottom, smart bar (opacity 0 + pointer-events none, no remount); InfoBanner and Coach stay. TopBar.jsx:51 Esc pre-check adds `!S.focusHide.value` so Esc exits focus instead of opening the menu.
Files: followmode.js (new), controller.js [lock] (follow :377, zoomTo :327, tap path :232-241, dblclick :244, per-frame :484), store.js, hud2.css, TopBar.jsx, InfoBanner.jsx follow button. Calls: M (about 35).
Checks: tests/followmode.test.mjs (node --test, fails first): saveHome once; esc/tap-empty -> restoreHome + showMenu; tap on B -> exit + select B; dbl/long B -> follow B, home unchanged, menu hidden; lost -> exit. Browser step tools/steps/follow-mode.mjs: follow a gecko, body.focus-hide and topbar opacity 0; Esc -> camera within 0.5 of home after 1.5 s, menu back; real dblclick on a skink and a touch long-press on a dartfrog (phone) -> S.following switches, menu hidden; desktop + phone + ?webgl, numbers only.
