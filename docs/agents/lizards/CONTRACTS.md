- `segmentFree(a, from, to)` (B4b, src/sim/occupancy.js, method of the occupancy grid): `from`, `to` = {x, y, z} at the body centre (the caller adds the lift). Returns t in [0, 1]: 1 = the segment enters no solid cell; else the fraction of the segment before the first cell it enters from free space. Exact 3D voxel walk over CELL; cells solid at `from` are ignored until left; returns 1 when the grid is empty or |to - from| < CELL (callers keep their end-point test). `a` = the animal or null, used only for counters (`sweepStats`). No allocation per call. Coordinate form (what animals.js calls): `segmentFreeAt(a, x0, y0, z0, x1, y1, z1, min = CELL / 3)`; `min = 0` sweeps every length (hop arcs in chords). Walkers: `walkFree(a, x0, y0, z0, x1, gy, z1, lift = 0.5)` sweeps to where the walker ends (its height if a piece is under the far end, else the ground gy).

## State dump row (Z0, tools/steps/state-dump.mjs; owner Z0, consumers every later check)
Run: `node tools/steps/state-dump-run.mjs --preset=karst --tier=standard --seed=1 --days=1 [--mix='gecko:3,skink:2'] [--every=10] [--speed=1] [--dt=0.1] [--hours=|--seconds=] [--care=1] [--only=a,b|--all=1] [--out=test-output/state/] [--url=http://127.0.0.1:4630/]`. Counters: `node tools/steps/state-counters.mjs <dump.jsonl>` (stuck, pile, waterTime, inSolid, tunnel, coverage, summary in tools/steps/state-counters.mjs).
- Clock: the main unit is the GAME DAY (`--days=N`, default 1). `--hours=N` = animal-time hours, `--seconds=N` = animal seconds (they win over `--days`). Game minutes per animal second `warp` = speed / min(speed, 4) (1x: 1 game min per animal s, so 1 game day = 1440 animal s and 1 animal hour = 2.5 game days). `--speed` (1|5|20|60) only sets `warp`; animals always move in `--dt` animal seconds per `move()`. Starts at `--start=6` o'clock of day 0.
- JSON lines, centimetres. One row per animal per sample (every `--every` animal s, default 10, also at t=0 and at the end); species that are prey of the tank's animals, eggs and sessile ones get no rows unless `--all=1` / `--only=`.
`{"t":120,"day":0,"hour":6.033,"id":"gecko-0","uid":57,"sp":"gecko","x":-12.34,"y":5.6,"z":3.2,"speed":1.2,"mode":"forage","doing":"Hunting a springtail","awake":1,"onWall":0,"wallMode":0,"perch":null,"swim":0,"inWater":0,"inSolid":0,"gx":-9.1,"gz":4.4,"gd":4.1,"tun":0}`
- `t` animal seconds since the start (`A.t`); `day` game day since the start; `hour` game clock 0-24 (lights 08-20). `id` = species-k (k = order of first appearance, stable between runs); `uid` = the game's `a.id` (not stable). `mode` = `a.hm.mode` | `a.sk.mode` | `a.state` (`a.state` until the herp mind exists). `speed` = `a.speedNow` cm/s. `doing` = `a.doing` (inspector text, null if none).
- `awake` = 0 when tucked asleep (`a.hit.tuck`) or in mode `hide` without a goal; else 1 (dead animals get no rows). `onWall` = `a.onWall`, `wallMode` = `a.wallMode`, `perch` = `a.perch.ph` or null, `swim` = `a.swimming`. `inWater` = pos.y below `waterTop(x,z)`. `inSolid` = the game's own occupancy test (`occ.insideBody`, `occ.inside` for swimmers), 0 for onWall/hop/wallMode.
- `gx,gz` = the goal (`a.hit.goal` for herp-mind animals, `a.target` otherwise; null when none); on the wall gz is the mind's plane value (-y); `gd` = distance to it in that plane, cm. `tun` = steps since the previous sample whose segment (checked every 0.5 cm, steps over 3 cm are relocations and skipped) crossed a solid between two free ends; counted in the page (a dump holds no solids and its samples are seconds apart, so it cannot be rebuilt from rows).
- First line `{"hdr":1,preset,tier,seed,every,dt,speed,warp,mix,care,startHour,frames,seconds,lights,species,sizes:{sp:body length cm (rig2.len; gecko 9.5, skink 16.8)},animals,placeMissed,gen}`; last line `{"end":1,frames,gameMinutes,thrown,errors,alive:[ids at the end],counts,stuckStats}`. Neither holds wall time or paths, so two runs of the same seed are byte-identical (wall time is in `<dump>.meta.json`). Counters skip `hdr`/`end`.
- Determinism: same preset/tier/seed/mix/flags => byte-identical `.jsonl`; no tolerance. `Math.random` and `performance.now` are replaced only inside page-side chunks, after the world is loaded, with the render loop stopped.
