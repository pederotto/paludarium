# Step scripts

Scripted flows for `tools/shot.mjs`, which drives the real game in the installed Chrome (real WebGPU) at a 16:9 desktop size and at a phone size:

```bash
npm run dev                                   # or: npm run build && npx vite preview --port 4173
node tools/shot.mjs --steps=tools/steps/<name>.mjs [--url=http://localhost:5173/] [--only=desktop|phone] [--out=test-output]
```

Each file exports `async (page, shot, name) => {}`; `shot('name')` saves a screenshot. Checks print `PASS`/`FAIL` or numbers, and most also print page errors at the end. Always look at both sizes. Files starting with `_` are helpers the others import.

Each script starts with a comment saying what it does; this is the map.

| Group | Scripts |
|---|---|

| **HUD and screens** | `hud2`, `hud2-career`, `hud2-lens`, `ui-review`, `banner`, `phone-codex`, `phone-dock`, `portrait`, `portrait-final`, `sizes-ui`, `fullscreen`, `fullscreen-tanks`, `photo`, `timelapse` |
| **Simulation checks** | `sim` (fast-forward, fails on NaN), `game-logic` (metrics, curator, commissions, events, vacation), `flies`, `flies-save`, `herps` (salamanders, newts, axolotls and geckos: modes per species, strikes and catches, stuck animals: PASS/FAIL), `turn` (standalone: how animals turn: yaw with the legs still, yaw rates, bend, and foot slip in forced half turns; docs/SKELETON.md), `genetics`, `humus`, `plantpond`, `water-conserve`, `water-flow`, `water-probe` (pump off, valves, dry intake, moving the pump out and back, into a pond, undo, markers: PASS/FAIL), `filter-flow` (each filter's flow at clog 0 / 0.5 / 1 and two head heights, hose sizes and water speeds; `node tools/steps/filter-flow.mjs` for the numbers alone), `erosion-aging`, `erosion-checks`, `placement`, `decor-ground` (standalone-ish: `PRESETS=cascade,suriname,streambank [SHOTS=1|2] node tools/shot.mjs --only=desktop --steps=tools/steps/decor-ground.mjs`, or `SCENES=starter,kits,editor` for the starter tank, every kit and editor placements; how each piece and plant meets the DRAWN ground: gap, burial, overlapping pieces, plants inside pieces, and the bark's texel density and stretch on wood), `stuck`, `crowding`, `clash` (what is DRAWN: animals' bodies overlapping each other, hardscape, the ground, the background or plant stems, per species, from the meshes and the transforms they are drawn with; `CLASH_SHOTS=n` adds pictures), `collide` (frogs, toads, geckos, newts and crabs as DRAWN: through the glass, in rocks, wood and plant stems, under the ground, behind the background, and the frame's spikes and flips while they climb; before/after numbers, pictures at the spots of the user's photos), `bugs-look` (insects and crustaceans in a running tank: a strip of frames per group, test-output/bugs), `eating`, `kits`, `kits-career`, `customtank`, `explorer-build`, `chem`, `deaths` |

| **Performance** | `skin-perf` (standalone: `node tools/steps/skin-perf.mjs --a=<before> --b=<after> [--webgl=1]`; the starter tank with frames uncapped, default view and a close view of a frog, A B B A: what the skinned near frogs cost), `perf` (starter, grand swamp, time-lapse), `frameprof` (the pieces of `Game.frame`), `drawcalls` (visible meshes by kind), `metrics` (the metrics recorder works in a real browser: PASS/FAIL; needs `--query="?metrics=step&nooverlay"` and a server with the collector, see the file).
